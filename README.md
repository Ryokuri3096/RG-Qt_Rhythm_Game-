# QT音游功能文档
  使用QT6.11制作,IDE为QT creator
### 界面架构

   主要有五个页面：主菜单、设置界面、选曲界面、游戏界面、个人账户界面
   
---
### 各界面功能清单

#### 一  主菜单界面

- 游戏标题与装饰展示
- Play按钮 → 进入选曲界面
- Settings按钮 → 进入设置界面
- Account按钮 → 进入个人账户界面
- 背景静态图或简单动态效果

#### 二 设置界面

- 音量调节（滑动条）
- 偏移延迟调节（适配音频延迟）
- 下落速度调节
- 按键绑定（四轨道按键自定义，默认S/D/J/K）
- 所有设置项持久化保存与自动加载
- 返回按钮回到主菜单

#### 三 选曲界面

- 曲目列表展示（曲名、难度、BPM、最高分、评级等）
- 列表项支持键盘上下选择、回车确认
- 选中曲目封面预览曲绘和音乐片段
- "开始"按钮进入游戏界面
- 提供各种曲目排序

#### 四 游戏界面

- 四列垂直轨道 + 一列特殊轨道(鼠标控制)
- 音符种类 : tap(大 / 小) 、hold 、drag 、搓碟音符
- 音画同步与对齐
- 键盘 / 鼠标输入捕获（S/D/J/K），按键时轨道底部高亮反馈
- 判定系统：Perfect / Good / Bad / Miss 四档
- 命中动画与音效反馈
- 实时分数计算与显示
- 连击数显示，Miss清零，高连击视觉变化等
- 暂停菜单（继续 / 重新开始 / 返回选曲）
- 结算界面（各判定数量、最高连击、总分、评级，重试或返回选曲）

#### 五 个人账户界面

- 昵称显示与修改
- AP\FC\clear数统计
- 各曲目最高分与最高评级
- 数据储存与账户的关联
